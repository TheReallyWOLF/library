# --- Данные ---

## Что такое JS

JavaScript (JS) — это высокоуровневый, интерпретируемый (с элементами JIT-компиляции), скриптовый язык программирования с динамической типизацией,
    прототипно-ориентированной объектной моделью, поддержкой нескольких парадигм (функциональной, объектно-ориентированной, императивной),
    однопоточностью (уже нет) с асинхронными механизмами (Event Loop, Promises, async/await) созданный по стандартизации через ECMAScript.

## Подробное описание
Высокоуровневый:  
    Абстрагируется от низкоуровневой работы с аппаратным обеспечением (памятью, процессором), 
    фокусируясь на логике программы. В JS нет прямого управления памятью или регистрами, 
    что упрощает разработку, но снижает контроль над производительностью по сравнению с C/C++.

Интерпретируемый:
    Код JS выполняется "на лету" интерпретатором браузера или Node.js (V8, SpiderMonkey),
    без предварительной компиляции в машинный код. В современных движках добавлена JIT-компиляция для ускорения, 
    но базово — интерпретация, позволяющая быструю итерацию (прототипирование) без сборки.

Скриптовый:       
    Язык для написания сценариев (скриптов) — небольших программ, автоматизирующих задачи. 
    В JS это скрипты, интегрированные в HTML (через <script>), для манипуляции веб-страницей, 
    а не самостоятельные приложения. Скрипты выполняются в runtime, без независимого файла.

Динамическая типизация: 
    Типы данных (string, number, object и т.д.) определяются автоматически во время выполнения, 
    без явного объявления типов (как в TypeScript). Переменная может менять тип на лету (var x = 5; x = "текст";),
    что гибко, но рискует ошибками (type coercion).

Прототипно-ориентированная: 
    Объекты наследуют свойства от прототипов, а не классов (как в Java). Объекты создаются с помощью литералов {} или конструкторов,
    и наследование происходит через цепочку прототипов, делая JS более гибким и функциональным, чем классическое ООП.

Много парадигменный: 
    Поддерживает несколько стилей: функциональный (работа с функциями как объектами, higher-order functions), 
    императивный (последовательные команды, циклы), ООП (через функции-конструкторы и ES6 классы, хоть и syntactic sugar). 
    Это позволяет писать код разными способами.

Однопоточный с асинхронностью: 
    JS выполняется в одном потоке (single-threaded), избегая races, но использует Event Loop, HTTP-запросы, 
    таймеры и Promises для асинхронных операций (неблокирующих I/O), что эффективно для веба.
    Однако, JS не полностью однопоточный: Web Workers (браузерные фоновые потоки), Worker Threads в Node.js, Atomics API (ES2020)

Стандартизация через ECMAScript (ES): 
    Официальный стандарт, развиваемый ECMA International с 1997;

Универсальный инструмент: 
    JS изначально был для интернета — чтобы делать сайты интерактивными но сейчас используеться везде
    Серверы: С Node.js JS работает на серверах, обрабатывая запросы сайтов (как ты пишешь код на одном языке для фронтенда и бэкенда).
    Мобильные приложения: С React Native или Cordova пишешь один код, и он запускается на iPhone/Android.
    Другое: Игры (с Phaser), анализ данных (работа с JSON), даже IoT-устройства (умные гаджеты).
    следует идеологии: "write once, run anywhere".

## Типы данных JS

### Примитивные типы (скалярные) (7 штук)
1. Boolean (логический) 1 бит (true/false). 
    Но в переменной — часто 1 байт из-за выравнивания. Пример: V8 может использовать бит в числе или массиве, чтобы экономить
2. Null (нулевой): Специальный тип, указывающий на "отсутствие значения" 
    0 байт в значении, но переменная занимает место (8 байт на 64-битной системе для адреса)
3. Undefined (неопределённый): По умолчанию присваивается переменным;
    0 байт в значении, но переменная занимает место (8 байт на 64-битной системе для адреса)
4. Number (число): (знак 1 бит, экспонента 11 бит, мантисса остальное) 31 - 64 битные числа с плавающей точкой;
5. BigInt (большое целое): минимум 64 бита + дополнительные блоки по 64 бита для больших чисел Для очень больших целых чисел;
6. String (строка): 2 байта (16 бит) Последовательность символов (UTF-16);
7. Symbol (символ): обычно ~16-24 байт Уникальный, неизменяемый идентификатор (введён в ES2015). Используется для ключей объектов, чтобы избежать конфликтов;

### Непримитивный тип (ссылочный)

8. Object (объект): Коллекция свойств (ключ-значение). Включает подтипы как масcивы (Array), функции (Function), даты (Date), регулярные выражения (RegExp), Map, Set и т.д.
   минимум 32-64 байта Зависит от количества свойств: каждый добавляет 8 байт ключа + 8 байт значения + slots
   
   Массив — это специализированный объект, который хранит упорядоченный, индексированный список элементов (любого типа);
   Функция — это особый объект, который содержит код и может быть выполнен (вызван);
